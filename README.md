# Reel Plan

Dashboard locale per pianificare la registrazione e la pubblicazione dei reel: hook, shot list, date di ripresa, caption e pipeline di stato.

## Avvio

Da PowerShell, nella cartella del progetto:

```powershell
cd C:\Users\skizz\Documents\GitHub\reel-planning
npm install
npm run dev
```

Poi apri nel browser: [http://localhost:5173](http://localhost:5173)

Il browser dovrebbe aprirsi da solo. I dati restano salvati in questo browser (localStorage).

## Script

| Comando | Cosa fa |
| --- | --- |
| `npm run dev` | Avvia l'app in sviluppo |
| `npm run build` | Compila per produzione |
| `npm run preview` | Anteprima della build |
